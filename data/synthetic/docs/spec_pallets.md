# Technical Data Sheet - Pallets (PL-EU-HT, PL-PL-1210)

## PL-EU-HT - Heat-treated wooden pallet
- Size: 1200 x 800 mm
- Certification: ISPM-15, heat treated to a core temperature of 56 degrees Celsius for at least 30 minutes, marked with the IPPC stamp.
- Moisture content: below 20%.
- Dynamic load (moving): 1,500 kg. Static load (on the floor): 4,000 kg. Racking load: 1,000 kg.
- Suitable for international export, including to the EU.

## PL-PL-1210 - Plastic pallet
- Size: 1200 x 1000 mm
- Material: virgin HDPE, washable, no splinters, suitable for cold storage down to minus 25 degrees Celsius.
- Dynamic load: 1,000 kg. Static load: 4,000 kg. Racking load: 600 kg.
- No ISPM-15 treatment is needed because it contains no wood.
- Weight: 12 kg per pallet.
